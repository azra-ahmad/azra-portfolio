# Azra Ahmad Algifari — Portfolio

Local first draft using Next.js, TypeScript, Tailwind CSS, and GSAP.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3001. Production validation: `npm run build`.

## Before publishing

- Replace `public/images/hero-portrait.png` with Azra's actual photograph. Current image is an AI-generated placeholder model.
- Replace illustrative project artwork and draft descriptions with approved screenshots and content.
- Add actual contact details. No recipient email is assumed.
- Confirm the About copy and project information.

The hero marquee and scroll animations respect reduced motion preferences. Project buttons open keyboard-accessible notes, with Escape to close.
